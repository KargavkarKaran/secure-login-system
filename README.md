# secure-login-system

<h3>Features</h3> 
<ul>
  <li> User Signup and Login</li>
  <li>🔒 Secure password hashing using bcrypt</li>
  <li>🔑 JWT (JSON Web Token) based authentication</li>
  <li> Protected routes accessible only to authorized users</li>
  <li> Secure handling of environment variables</li>
  <li>Prevention of unauthorized access to APIs</li>
</ul>

<h3>Security Measures Implemented</h3>

<ul>
  <li>Passwords are never stored in plain text</li>
  <li>JWT tokens used for authentication</li>
  <li>Protected API routes using middleware</li>
  <li>Environment variables used for sensitive data</li>
  <li>Proper error handling to prevent data leakage</li>
</ul>
